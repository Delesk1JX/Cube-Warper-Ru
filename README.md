# Cube Warper-Ru

Информация: Перевод квестов и прочего контента в сборке Cube Warper. Ссылка на [сборку](https://www.curseforge.com/minecraft/modpacks/cube-warper)

Установка: Пример для Prism Launcher:

Скопировать с заменой файлы в корневую директорию сборки. Например, C:\Users\user\AppData\Roaming\PrismLauncher\instances\CubeWarper\minecraft

После запустите игру и проверьте работу перевода.

Если найдёте какие-то ошибки, можете сообщить о них мне в дискорд: narik_20

Для перевода модов использовал:

[RTF Extension](https://modrinth.com/resourcepack/rtf-extension)
